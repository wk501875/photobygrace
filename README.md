# Here by Grace 네컷 (성도교제의 밤 포토부스)

노트북 웹캠으로 4컷을 찍고, 완성된 사진을 저장소(기본: Cloudflare R2)에 올린 뒤 **QR 코드**로 나눠 주는 포토부스입니다.
인쇄는 하지 않고, 성도분들이 QR을 찍어 각자 휴대폰에 사진을 받아 가요.

- 촬영 화면: https://photobygrace.pages.dev
- 사진 관리: https://photobygrace.pages.dev/admin (관리자 비밀번호)

```
photobygrace/
├─ index.html          촬영 화면
├─ config.js           행사 문구·프레임·사진 칸 위치·업로드 주소 설정
├─ vendor/qrcode.js    QR 생성 라이브러리
├─ frames/             디자인한 프레임 PNG를 넣는 곳
├─ functions/          Cloudflare Pages Functions (서버 쪽)
│  ├─ api/upload.js    사진 업로드 → R2 저장
│  ├─ p/[id].js        QR을 찍으면 열리는 다운로드 페이지
│  ├─ img/[id].js      사진 파일
│  └─ admin/           사진 관리 페이지 (목록·저장·삭제)
└─ apps-script/Code.gs 구글 드라이브로 바꿀 때 쓰는 예비 코드
```

## 1. Cloudflare R2 연결 (최초 1회)

1. **R2 켜기**: Cloudflare 대시보드 → **R2 Object Storage** → 처음이면 결제 수단 등록 후 활성화
   (무료 한도: 저장 10GB/월, 다운로드 전송 무료)
2. **버킷 만들기**: **Create bucket** → 이름 `photobygrace-photos` → 위치는 자동
3. **Pages에 연결**: **Workers & Pages** → `photobygrace` → **Settings** → **Bindings** → **Add** → **R2 bucket**
   - Variable name: `PHOTOS`
   - R2 bucket: `photobygrace-photos`
4. **비밀번호 두 개 넣기**: 같은 **Settings** → **Variables and Secrets** → **Add** (Type: **Secret**)
   - `EVENT_CODE`: 촬영 노트북에서 업로드할 때 쓰는 행사 코드 (예: 영문+숫자 8자 이상)
   - `ADMIN_PASSWORD`: 사진 관리 페이지 비밀번호
5. **다시 배포**: **Deployments** → 최신 배포 오른쪽 `…` → **Retry deployment**
   (설정은 다음 배포부터 적용돼요)
6. 촬영 기기에서 사이트를 열고 오른쪽 아래 **설정 → 행사 코드**에 `EVENT_CODE`와 같은 값을 넣고 저장합니다.
   행사 코드를 넣으면 성도분들이 건드리지 않게 **설정 버튼이 사라져요.**
   다시 열려면 화면 **오른쪽 위 모서리를 2초 동안 길게 누르세요.**

### 사진 자동 삭제 (권장)

R2 → `photobygrace-photos` → **Settings** → **Object lifecycle rules** → **Add rule**
→ 접두사 `p/`, **Delete objects** after **45일** 처럼 설정하면 행사 후 사진이 자동으로 지워져요.
(2주 행사 + 받아 갈 여유 기간)

### 저장소를 바꾸고 싶을 때

`config.js`의 `uploadUrl`만 바꾸면 됩니다.

- Cloudflare R2 (기본): `"/api/upload"`
- 구글 드라이브: `apps-script/Code.gs`를 Apps Script 웹 앱으로 배포하고 그 주소(`https://script.google.com/.../exec`)를 넣기
  (폴더 만들기 → 코드 붙여 넣고 `FOLDER_ID` 입력 → 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자)

## 2. 행사 당일 실행

1. 노트북 크롬에서 https://photobygrace.pages.dev 를 엽니다. 카메라 권한을 물으면 **허용**.
   - 화면에 자물쇠 그림만 나오면 카메라 가림막이나 키보드의 카메라 끄기 키(F8~F10 등)를 확인하세요.
2. 외장 웹캠을 쓰면 **설정 → 카메라**에서 고릅니다.
3. 큰 모니터나 TV에 연결하고 `F11`로 전체 화면.
4. **홈 화면**(큰 HERE BY GRACE 타이틀)을 아무 데나 누르면 **촬영 화면**으로 넘어가요.
   카메라를 보며 자리를 잡고 **촬영 시작**(또는 스페이스바) → 5초 카운트다운 × 4컷 → 자동 업로드 → QR 표시.
   촬영 화면에서 2분 동안 아무것도 안 하면, 결과 화면에서는 QR이 뜨고 90초가 지나면 홈 화면으로 돌아가요.
   무선 프레젠터(발표용 리모컨)의 버튼이 보통 스페이스/엔터라 리모컨으로도 찍을 수 있어요.
5. 마음에 안 드는 컷은 아래 작은 사진을 눌러 그 컷만 다시 찍습니다. 다시 찍으면 새 QR이 나옵니다.
6. **다음 분 촬영하기**로 넘어갑니다. 아무도 누르지 않으면 QR이 뜬 뒤 90초가 지나 자동으로 처음 화면으로 돌아가요
   (업로드에 실패한 사진은 자동으로 넘어가지 않아요). 포즈 안내 문구와 시간은 `config.js`의 `poses`, `idleReset`에서 바꿀 수 있어요.

**설정 → "이 기기에도 자동 저장"** 이 켜져 있으면 모든 사진이 노트북 `다운로드` 폴더에도 백업됩니다.
인터넷이 끊겨도 사진은 노트북에 남아요.

### 태블릿으로 운영할 때 (아이패드 / 갤럭시탭)

1. **홈 화면에 추가해서 전체 화면으로 쓰기**
   - 아이패드(사파리): 공유 버튼 → **홈 화면에 추가** → 홈 화면의 "네컷" 아이콘으로 실행
   - 갤럭시탭(크롬/삼성 인터넷): 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
   - 주소창 없이 꽉 찬 화면으로 열려요. 처음 실행할 때 카메라 권한을 **허용**.
2. **설정 → 행사 코드** 입력 (홈 화면 앱은 브라우저와 따로 기억하니 앱에서 한 번 더 입력)
3. **다른 앱으로 못 나가게 잠그기**
   - 아이패드: 설정 → 손쉬운 사용 → **사용법 유도된 접근** 켜기 → 앱에서 측면(홈) 버튼 세 번 눌러 시작
   - 갤럭시탭: 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → **앱 고정** 켜기 → 최근 앱 화면에서 앱 아이콘 → 이 앱 고정
4. **화면 꺼짐**: 앱이 촬영 중 화면을 켜 두도록 요청하지만, 기기 설정의 자동 잠금도 **안 함**(또는 최대)으로 바꿔 두세요.
5. **충전기는 꼭 연결**. 카메라를 계속 켜 두면 배터리가 빨리 닳아요.
6. 가로·세로 모두 됩니다. 세로로 세우면 위가 카메라, 아래가 버튼이고, 촬영이 끝나면 사진과 QR이 화면 가득 나와요.
7. 태블릿은 **자동 백업 저장이 기본으로 꺼져 있어요** (찍을 때마다 다운로드 알림이 떠서). 사진은 R2에 저장되고 `/admin`에서 볼 수 있어요.
8. 블루투스 발표용 리모컨(스페이스/엔터 키를 보내는 제품)을 연결하면 리모컨으로 촬영할 수 있어요.
   셀카봉용 블루투스 셔터는 볼륨 키를 보내는 경우가 많아 웹에서는 동작하지 않을 수 있어요.

### 촬영 순서

홈 화면 → **① 프레임 고르기**(사진 모양 → 디자인) → **② 필터·스티커 고르고 촬영** → QR

- 사진 모양은 `config.js`의 `layouts`에서 칸 위치를 고치거나, 지워서 숨길 수 있어요. 칸 비율이 카메라 화면 비율이 돼요.
- **스티커**: 촬영 화면의 스티커 목록에서 눌러 추가하고(최대 8개), 카메라 화면에서 손가락으로 끌어 옮겨요. 고른 스티커는 "작게 / 크게 / 지우기"로 조절해요. 찍힌 사진에도 같은 자리에 들어가요.
  - 그림은 `stickers/` 폴더의 투명 이미지(WebP/PNG)이고, 목록·이름·처음 크기와 위치는 `config.js`의 `stickers`에서 바꿔요.
  - 새 스티커를 넣으려면 투명 배경 이미지를 `stickers/`에 넣고 `stickers` 목록에 한 줄 추가하세요 (`src`로 파일 경로 지정 가능).

### 홈 화면 배경 영상

- 홈 화면 뒤에 `media/home-loop.mp4`(8초, 소리 없음)가 반복 재생돼요. 홈 화면일 때만 재생되고 촬영 중에는 멈춰요.
- 홈 화면에 들어올 때마다 제목 → 말씀 → 출처가 흐릿했다 또렷하게 차례로 뜨고, 이어서 "TOUCH TO START" 버튼이 나타나요. 화면 어디를 눌러도 시작돼요.
- 대기 중에는 배경이 아주 천천히 줌인돼요. 홈 화면 말씀은 `homeVerse`에서 바꿔요.
- 오른쪽 위 버튼으로 전체 화면을 켤 수 있어요 (홈 화면에 추가한 앱으로 열었거나 이미 전체 화면이면 숨겨져요).
- 바꾸려면 같은 이름으로 덮어쓰거나 `config.js`의 `homeVideo`, `homePoster`(첫 장면 이미지)를 고치세요. 빼려면 `homeVideo: ""` → 예전 흑백 홈 화면.

### 여러 장 찍고 고르기

- 컷 수보다 2장 더 찍고(세로 4컷·2×2면 6장, 큰 2컷 4장, 단체 1컷 3장) 마음에 드는 컷을 골라 프레임에 넣어요.
- 처음 N장이 미리 골라져 있고, 누르면 빠지고 다시 누르면 다음 칸에 들어가요. 왼쪽에 고른 사진으로 만든 미리보기가 바로 보여요.
- 60초 동안 아무것도 안 하면 지금 고른 사진으로 자동 완성돼요 (사진을 잃지 않게).
- 끄려면 `config.js`의 `pickMore: false` 또는 태블릿 설정의 "여러 장 찍고 마음에 드는 컷 고르기" 해제. 더 찍을 장수는 `extraShots`.

### 필터 · 말씀

- 촬영 화면에서 **필터**(원본 / 뽀샤시 / 흑백 / 필름 / 은혜의 빛)를 고를 수 있어요. 카메라 화면에 바로 미리 보여요.
- 홈 화면으로 돌아가면 `config.js`의 `layout`, `frame`, `look` 기본값으로 다시 맞춰져요.
- **은혜 말씀은 촬영할 때마다 랜덤**으로 하나 뽑혀 모든 디자인에 들어가요(개역한글). `config.js`의 `verses` 목록에서 추가·삭제할 수 있고, 길면 글자가 자동으로 작아져요. 빼려면 `verse: false` (그러면 삼상 7:12 고정).

### 프레임 = 사진 모양 × 디자인

프레임 고르기 화면에서 **① 사진 모양**을 고르고 **② 디자인**을 골라요. 왼쪽에 고른 조합이 크게 미리 보여요.

- 사진 모양 4가지: 세로 4컷 · 2×2 4컷 · 큰 2컷 · 단체 1컷 (`layouts`)
- 디자인 7가지: 흰색 · 검정 · 파스텔 무지개 · 화이트 미니멀 · 은혜 여권 · 성도교제의 밤 · 홀로그램 (`styles`, 처음 선택은 `frame`)
- 어떤 모양에도 모든 디자인이 입혀져요 (4 × 7 = 28가지). 그리는 코드는 `frames.js`.
  - 디자인은 시안(400×1200) 단위로 적혀 있고, 첫 칸 위 여백 = 160 × u, 마지막 칸 아래 여백 ≈ 134 × u에 제목·말씀이 들어가요.
  - 칸 위치를 고칠 땐 이 여백을 남겨 두면 글자가 사진과 겹치지 않아요.

## 3. 사진 관리

https://photobygrace.pages.dev/admin 에 들어가면 브라우저 로그인 창이 뜹니다.
아이디는 아무거나, 비밀번호는 `ADMIN_PASSWORD`. 최신순 목록에서 사진을 저장하거나 삭제(두 번 눌러 확인)할 수 있어요.

## 4. 프레임 문구 바꾸기

- 흰색·검정 디자인의 제목·부제·날짜: `config.js`의 `title`, `subtitle`, `footer`
- 다른 디자인의 글자는 `frames.js`에서 바로 고쳐요.

## 로컬에서 테스트

```bash
npx wrangler pages dev . --r2 PHOTOS --binding EVENT_CODE=test1234 --binding ADMIN_PASSWORD=pw
```

http://localhost:8788 에서 촬영 → 설정의 행사 코드에 `test1234` 입력.

## 준비물 체크리스트

- 노트북 + 크롬, 웹캠(노트북 내장도 가능), 모니터/TV
- **인터넷** (교회 와이파이 또는 휴대폰 핫스팟) — QR 업로드에 필요
- 조명 (링라이트 하나만 있어도 사진이 훨씬 밝아요)
- 소품, 포토존 배경
- 안내문: "사진은 QR로 받아 가실 수 있고, 행사 종료 후 ○○일에 삭제됩니다"

## 참고

- QR을 찍으면 그 사람 사진 한 장만 보이는 페이지가 열립니다. 다른 사진 목록은 공개되지 않아요.
- 사진 한 장 약 1MB. R2 무료 10GB면 수천 장도 충분합니다.
- R2에는 요금 상한 기능이 없으니, 행사 코드와 자동 삭제 규칙을 꼭 설정해 두세요.
